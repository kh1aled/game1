# 🕌 Kids Prayer Learning Game  
A simple and fun educational game designed to teach children the Five Daily Prayers (Salah) in an interactive and engaging way.  
Built with **HTML**, **CSS**, and **JavaScript** — no backend required.

---

## 🎯 About the Project
This project helps young children learn the names, times, and number of rak'ahs (units) of the five Islamic prayers through a friendly and colorful interface.  
The game uses interactive cards, quick quizzes, and visual feedback to encourage learning while keeping it fun.

---

## ✨ Features
- 🕌 Learn the Five Daily Prayers (Fajr, Dhuhr, Asr, Maghrib, Isha)
- ⏱ Displays prayer time and number of rak'ahs
- 🎮 Simple interactive quiz for each prayer
- 🎨 Child-friendly UI with bright colors and simple layout
- 🔊 Optional sound effects for correct/wrong answers
- 📱 Fully responsive — works on mobile, tablet, and desktop
- 🚫 Works offline — no backend or installation required

---

## 🛠 Technologies Used
- **HTML5**  
- **CSS3 (Flexbox / Grid)**  
- **JavaScript (Vanilla JS)**
